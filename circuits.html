Reference


Boolean laws
A+0=A · A·1=A
A+A′=1 · A·A′=0
De Morgan: (AB)′=A′+B′ and (A+B)′=A′B′
Absorption: A+AB=A
XOR: A⊕B = AB′+A′B


Universal gates
NAND alone, or NOR alone, can build every other gate. NOT = NAND(A,A). AND = NOT of NAND. OR = NAND(A′,B′).


Normal forms
Sum of products (SOP) ORs the minterms where the output is 1. Product of sums (POS) ANDs the maxterms where it is 0. Karnaugh maps group adjacent minterms to simplify.


Sequential logic
Latches and flip-flops (SR, D, JK, T) add memory with feedback. Combinational outputs depend only on current inputs; sequential outputs also depend on stored state.


Quantum gates
X: [[0,1],[1,0]]
Z: [[1,0],[0,−1]]
H: (1/√2)[[1,1],[1,−1]]
S: diag(1,i) · T: diag(1,e^{iπ/4})
CNOT flips target if control is 1


Entanglement
H on q0 then CNOT gives the Bell state (|00⟩+|11⟩)/√2: the two qubits are always measured equal, yet each alone looks random. GHZ extends this to three.


Reversibility
Quantum gates are unitary, so every one is reversible and none can copy an unknown state (no-cloning). Classical AND and OR lose information; Toffoli and Fredkin gates are reversible classical gates.


Measurement
Measuring collapses the state. The chance of outcome k is |amplitude|². Phase never shows in a single measurement but drives interference between gates.


Karnaugh maps
Order rows and columns in Gray code so neighbours differ by one bit. Circle rectangles of 1s with sizes 1, 2, 4, 8. Bigger groups give simpler terms, and groups may wrap around the edges.


Flip-flop equations
D: Q⁺ = D
T: Q⁺ = T ⊕ Q
JK: Q⁺ = JQ′ + K′Q
SR: Q⁺ = S + R′Q (SR = 0)


Number systems
Two's complement negates by inverting all bits and adding 1. An n-bit value spans −2ⁿ⁻¹ to 2ⁿ⁻¹−1. One hex digit is exactly 4 bits and one octal digit 3 bits.


Gate identities
HZH = X · HXH = Z
S² = Z · T² = S
SWAP = 3 CNOTs
CZ = (I⊗H) CNOT (I⊗H)


Quantum algorithms
Grover searches N items in about √N steps. Deutsch–Jozsa separates constant from balanced functions in one query. Shor factors integers using the quantum Fourier transform. Teleportation moves a state using a Bell pair and two classical bits.
